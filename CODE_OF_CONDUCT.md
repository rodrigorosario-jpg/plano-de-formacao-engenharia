# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), cujo texto completo vale aqui.

Em resumo:

- trate as pessoas com respeito, em issues, PRs e comentários;
- critique o trabalho, não a pessoa;
- sem assédio, ofensa ou exposição de dados de outras pessoas.

Para relatar uma violação, abra o relato privado em **Security → Report a vulnerability** e diga que é sobre conduta. O mantenedor avalia e pode editar ou apagar comentários, fechar issues e bloquear contas.
