# Roteiro dos módulos de nivelamento

Este é o roteiro comum dos módulos de nivelamento (NM, NF e NL). Cada módulo aponta para cá na seção "Como estudar este módulo". O NM0 tem roteiro próprio, ligado às suas listas.

Os níveis de exercício seguem a tabela [Níveis de exercício](../AVALIACOES.md#níveis-de-exercício) de AVALIACOES.md.

1. **Diagnóstico.** Use o resultado do módulo no diagnóstico do bloco. Com 85% ou mais, vá direto para a prova de saída; se passar, o módulo fica `dispensada`. Entre 60% e 84%, estude só os tópicos em que errou. Abaixo de 60%, faça o módulo inteiro.
2. **Estudo guiado.** Para cada tópico: leia ou assista a explicação, refaça os exemplos sem olhar, depois faça exercícios dos níveis 1 e 2.
3. **Aplicação.** Resolva ao menos três problemas de nível 4 (Contexto), ligados às aplicações listadas no módulo.
4. **Prova de saída.** Peça a prova de saída quando acertar 80% de uma lista mista sem consulta.
5. **Revisão espaçada.** Depois do portão, revisões curtas em 7, 30 e 90 dias. O script avisa quando vencem.

O critério do portão de cada módulo está na seção "Portão de saída" do próprio módulo. As regras de decisão, inclusive a de autonomia, estão em [AVALIACOES.md](../AVALIACOES.md#regras-de-decisão).
