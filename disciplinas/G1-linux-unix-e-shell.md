# G1 · Linux, Unix e shell

Semestre 2 · 60 h previstas · nível-alvo 4

## Tópicos, na ordem

Sistema de arquivos, processos, permissões, shell scripting, ferramentas de texto, chamadas de sistema, serviços.

## Referência principal

William Shotts, The Linux Command Line; MIT Missing Semester.

## Competência ao concluir

Administrar e automatizar uma máquina Linux pela linha de comando.

## Portão de saída

Uma tarefa real automatizada em shell; uma semana de trabalho só no terminal. A disciplina só é concluída quando o portão é cumprido de forma individual, com a entrega funcionando e defendida numa explicação oral.
