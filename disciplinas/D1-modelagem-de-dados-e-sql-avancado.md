# D1 · Modelagem de dados e SQL avançado

Semestre 10–11 · 50 h previstas · nível-alvo 5

## Tópicos, na ordem

Modelagem relacional e dimensional, OLTP e OLAP, funções de janela, CTE, planos de execução, indexação e tuning.

## Referência principal

Kimball e Ross, The Data Warehouse Toolkit; Markus Winand, SQL Performance Explained.

## Competência ao concluir

Modelar um domínio para transação e para análise e otimizar consultas pelo plano.

## Portão de saída

Modelo dimensional de um domínio real; cinco consultas otimizadas pelo plano. A disciplina só é concluída quando o portão é cumprido de forma individual, com a entrega funcionando e defendida numa explicação oral.
