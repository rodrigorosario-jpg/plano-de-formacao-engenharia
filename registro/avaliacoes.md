# Registro de avaliações

Uma linha por avaliação. Tipos: `diagnostico`, `exercicios`, `saida`, `revisao`, `laboratorio` (veja [AVALIACOES.md](../AVALIACOES.md)). Em Códigos, liste os módulos cobertos, separados por vírgula. Para um diagnóstico de bloco, use uma linha por módulo, com os acertos daquele módulo. Em Lista, quando a avaliação veio de uma lista ou prova do repositório, coloque o caminho do arquivo (por exemplo `exercicios/NM0/4-divisao.md`): o `--checar` confere se os acertos batem com as linhas de `registro/respostas.csv` daquela data e lista.
