**O roteiro do nível 3** (guia: `guias/NG1/3-branches.md`, competência NG1.c04):

1. **Antes de ler o guia, uma pergunta para você pensar:** se uma branch é só um ponteiro para um commit, o que você espera que aconteça com a `main` quando você faz um commit estando em outra branch? E o que acontece com os commits quando você apaga uma branch? Me responda com as suas palavras, mesmo que seja um chute. Depois a gente confere com o guia.
2. **Exercício básico** (num repositório de brinquedo): crie `exp` a partir da `main`, faça dois commits nela, volte para a `main` e confira com `ls` e `git log --oneline --all --graph`. Antes de rodar o `ls`, preveja: os arquivos da `exp` vão aparecer na pasta?
3. **Exercício intermediário** (por escrito, faz parte do critério de conclusão do nível): você está na `main` com `notas.txt` modificado e não commitado, e o `git switch exp` responde *"Your local changes would be overwritten"*. Explique por que o Git recusou e liste três saídas, dizendo o que cada uma faz com a sua mudança. Pode me mandar a resposta que eu corrijo.
4. **Laboratório, sem consulta:** os dois cenários do nível 3. Eles rodam na sua máquina, cada um numa pasta nova, fora do repositório:

   ```bash
   python scripts/laboratorio_git.py enunciado N3-criar-branch
   python scripts/laboratorio_git.py preparar N3-criar-branch /tmp/lab-n3-criar
   # ... resolva dentro de /tmp/lab-n3-criar ...
   python scripts/laboratorio_git.py conferir N3-criar-branch /tmp/lab-n3-criar
   ```

   O mesmo vale para `N3-limpar-branches` (com outra pasta, por exemplo `/tmp/lab-n3-limpar`). Quando o `conferir` terminar com `Cenário <código> resolvido.`, cole a saída aqui que eu registro.

Lembrete da regra de ouro: treine sempre em repositórios descartáveis, nunca na `main` nem na sua branch de estudo.
