## O que vem depois (para você já ter o mapa)

O treino prático de cada nível são os cenários do laboratório. Os do nível 1 são:

- `N1-primeiro-commit`: primeiro commit, escolhendo o que entra;
- `N1-staging-parcial`: commitar só parte das mudanças.

Cada um roda numa pasta descartável, fora do repositório de estudos:

```bash
python scripts/laboratorio_git.py enunciado N1-primeiro-commit
python scripts/laboratorio_git.py preparar N1-primeiro-commit /tmp/lab-n1-a
# ... resolva com os seus comandos, dentro de /tmp/lab-n1-a ...
python scripts/laboratorio_git.py conferir N1-primeiro-commit /tmp/lab-n1-a
```

Para o portão da NG1 contam os 10 cenários (níveis 1 a 5) resolvidos sem consulta, em pelo menos 3 dias diferentes, mais uma explicação oral de um merge com conflito. Quando um `conferir` passar, cole a saída aqui que eu registro com você.

Uma regra para todo o módulo: nunca treine na `main` nem na sua branch de estudo, porque elas são o seu registro de verdade. Exercício que escreve no Git vai sempre numa pasta ou num clone descartável.
