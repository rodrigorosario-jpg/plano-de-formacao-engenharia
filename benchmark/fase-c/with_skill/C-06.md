Sem computador · tempo indicativo: 20 a 30 minutos.

Rastreie cada programa à mão, numa tabela com uma coluna por variável e uma linha por volta do laço.
Legenda: `%` é o resto da divisão inteira (7 % 3 = 1); `//` é a divisão inteira (7 // 2 = 3); `range(a, b)` gera os inteiros de a até b − 1.

**Nível 1 · Fixação**

1. O que este programa imprime?

```
i = 1
while i < 20:
    i = i * 3
print(i)
```

**Nível 2 · Aplicação**

2. O que este programa imprime?

```
soma = 0
for k in range(1, 6):
    if k % 2 == 1:
        soma = soma + k
print(soma)
```

3. O que este programa imprime?

```
n = 50
passos = 0
while n > 1:
    n = n // 2
    passos = passos + 1
print(passos)
```

4. O que este programa imprime?

```
x = 10
y = 0
while x > 0:
    if x % 3 == 0:
        y = y + x
    x = x - 2
print(y)
```
