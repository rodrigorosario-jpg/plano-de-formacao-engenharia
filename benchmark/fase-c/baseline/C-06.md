```python

passos = 0
while x < 20:
    x = x * 2
    passos = passos + 1
print(passos)
```

**3.** O que o programa imprime? Na tabela, inclua uma coluna dizendo qual ramo do `if` rodou em cada volta.
```python
total = 0

    else:
        total = total + 1
print(total)
```

vezes = 0
while i <= 10:
